# DONE LOG (простое описание выполненных пунктов)

Этот файл нужен для короткого отчета по каждому завершенному пункту.

Правило:
- Сначала отмечаем пункт как `[x]` в `TODO.md`.
- Сразу после этого добавляем сюда короткое описание: что именно сделали простым языком.

## Формат записи

```md
### YYYY-MM-DD — <название пункта из TODO>
Что сделали: <1-3 коротких предложения без сложных терминов>.
```
